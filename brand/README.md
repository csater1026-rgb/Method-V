# Method V brand files

PNG versions of the logo for places that need an upload (Stripe → Settings →
Branding and Connect branding, app stores, social profiles). Rendered from
the site's own Wordmark and `src/app/icon.svg`, so they match the site.

- `method-v-icon.png`: square icon, 512×512, pixel V on black.
- `method-v-logo-white.png`: wordmark in white, transparent background (for dark backgrounds).
- `method-v-logo-dark.png`: wordmark in navy, transparent background (for light backgrounds).
- `method-v-logo-on-navy.png`: white wordmark on the site's navy (#0a1624).

Colors: navy `#0a1624`, blue `#0379d9`, cyan `#40f4f5`, mint `#82ed9d`.
